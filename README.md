# DEEMI SAR Review

A finished run of the SAR photo-triage system over a drone survey of Enfield,
Maine. Type a description of a missing person and the batch re-orders; click any
photograph to zoom, pan and see where it was taken.

Static demo — no server, no account. Ranking here uses the lightweight
keyword scoring; the live application additionally runs a vision-language
model over the top of the ranking.

Not indexed by search engines. Source is kept privately.
